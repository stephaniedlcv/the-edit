Objetivo:
Crear un flujo funcional para añadir una pieza nueva al closet.

Ruta deseada:
- /closet/add

Flujo esperado:
1. Usuario entra a /closet/add.
2. Ve una pantalla premium consistente con THE EDIT.
3. Puede llenar campos básicos:
   - name
   - category
   - type/subcategory si existe
   - colorFamily
   - colorName
   - size
   - itemStatus
   - brand
   - purchaseSource
   - paidPrice
   - purchaseDate
   - productUrl
   - notes
   - stylingNotes
   - vibes/tags
   - scores si el form existente ya los soporta
4. Puede subir imagen.
5. Al guardar, se crea la pieza.
6. Si hay imagen, se sube y se asocia a la nueva pieza.
7. Al terminar, redirige a /closet/item/[newId].
8. Cancel vuelve a /closet/gallery.

Importante:
- Reutilizar closet-item-edit-form.tsx si se puede adaptar a create mode.
