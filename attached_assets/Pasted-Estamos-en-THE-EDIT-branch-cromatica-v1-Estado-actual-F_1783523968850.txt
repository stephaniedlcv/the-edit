Tareas:

1. Crear `src/components/ui/button.tsx`
Debe exportar un componente `Button`.
Debe soportar:
- `variant`: `"solid" | "outline" | "ghost"`
- `size`: `"sm" | "md" | "lg"`
- `asChild` opcional si el proyecto ya usa patrón Slot; si no, no añadir dependencia nueva.
- props normales de button.
- estilos usando tokens Cromática.
- focus visible.
- disabled state.
- sin colores decorativos fuera de tokens.

2. Crear `src/components/ui/chip.tsx`
Debe exportar `Chip`.
Debe soportar:
- `variant`: `"default" | "active" | "outline" | "color"`
- `size`: `"sm" | "md"`
- `colorFamily?`
- si recibe `colorFamily`, usar `getColorFamilyMeta()` de `src/lib/wardrobe/spectrum.ts`.
- si la familia tiene `borderHex`, usarlo para borde.
- si `kind === "special"`, no fingir que es hue normal: usar tratamiento simple y honesto por ahora, por ejemplo borde + texto, sin inventar gradiente complejo todavía.
- focus visible si es interactivo.
- debe poder renderizar como `button` o `span` según props simples. Si complica, dejarlo como `span` visual y crear variante interactiva más adelante.

3. Crear `src/components/ui/section-head.tsx`

- `eyebrow?`

- `action?` opcional para nodo React
Debe usar tipografía/tokens Cromática.
